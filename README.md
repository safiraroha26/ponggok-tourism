# Ponggok Tourism

A tourism website for Ponggok Village, showcasing its history, accommodations, gallery, and local tourist destinations.

## Overview

Ponggok Tourism is a website project created to introduce the tourism potential of Ponggok Village through a simple web-based platform.

The website provides information about Ponggok Village, its history, accommodations, gallery, and several tourist destinations.

This repository contains the **initial version of the project**, which will be used as the foundation for future redesign and improvements.

## Pages

The current website includes:

- **Home** — Main landing page
- **History** — Information about the history of Ponggok Village
- **Accommodation** — Accommodation information
- **Gallery** — Photo gallery
- **Tourism** — Overview of tourist destinations

### Tourist Destinations

- Umbul Besuki
- Umbul Ponggok
- Umbul Sigedang
- The Honduras
- Soko Alas

Each destination has its own dedicated HTML page.
